Fire Emblem: Fortune's Weave natively on PC

fefw-recomp translates the Nintendo Switch 2 game code into C++ and compiles it into a regular Windows program running on a lightweight Vulkan 1.3 runtime. It is not an emulator.

Built for PC from the ground up

Everything the console game offers, paired with modern display, input, performance, and modding features.

Native Execution

Game code is statically recompiled to native x64 C++ and rendered directly via Vulkan 1.3 — no emulator overhead in between.

60 / 120 FPS & Ultrawide

Play at 60 or 120 FPS at any output resolution, with native 21:9, 32:9, or wider aspect ratios and a centered 16:9 HUD.

DLSS, FSR 3 & XeSS

Built-in TAAU plus optional DLSS, AMD FSR 3, and Intel XeSS upscaling, DLSS & FSR 3 frame generation, and LSFG-VK on Linux.

True HDR Output

Full HDR presentation with separate brightness controls for the 3D scene and the menus/HUD, plus windowed, borderless, or fullscreen.

Controllers, Mouse & HD Rumble

Seamless switching between keyboard, native Joy-Con 2 PC mouse mode, and any controller, with DualSense/Pro HD Rumble and Xbox 4-motor rumble.

Mods, DLC & In-Game Overlay

Supports RomFS mods, exefs .ips/.pchtxt patches, native DLL code mods, your own dumped DLC, all game languages, and an F1 live overlay.

Steam Deck & handhelds

One-file installer

In Desktop Mode, download one file and open it. It installs the game, Decky Loader and the fefw-recomp plugin, and adds the game to your Steam library with artwork, asking before each step.

Download Installer
  1. Switch to Desktop Mode and download fefw-recomp-install.desktop. If your browser saves it ending in .download, remove that ending.
  2. Open the file (choose to run it if asked) and answer its questions.
  3. In the launcher it opens, choose your dump and press Set up.
  4. Back in Game Mode, play from your library. The plugin in the Quick Access Menu updates and rebuilds the game and changes its main graphics settings.

For SteamOS-style handhelds; the Decky plugin is early. So far tried on CachyOS Handheld, not yet on SteamOS or Bazzite. On Bazzite, install Decky Loader first with ujust setup-decky.

    Getting Started

    The included launcher verifies your dump, compiles the game on your PC, and prepares shaders automatically.

    Quick Setup

    1. Download & extract fefw-recomp-<version>-win64.zip into its own folder.
    2. Run fefw-launcher.exe and open the Setup page.
    3. Select your dump (a folder with exefs\ & romfs\, a base\ + updates\ folder, or a .nup package) and click Set up. You can pause and resume anytime.
    4. Press Play. Your saves are stored in save\ next to the launcher; press F1 in-game for the settings overlay.

    Updating: Extract the new release to a new folder, copy over your save\ (and mods\) folder, and run Set up again.

    1. Download & extract fefw-recomp-<version>-linux-x64.tar.gz and run fefw-launcher.AppImage.
    2. Select your dump on the Setup page and click Set up to build the game and prepare shaders.
    3. Play via Proton: Play uses Steam Proton, umu-run, or Wine — or click Add to Steam on the Play page to launch from Steam (including Steam Deck Game Mode).
    4. Frame Generation: Install LSFG-VK from Settings > Frame rate (requires Lossless Scaling on Steam).

    On a handheld? The one-file installer does these steps for you and adds updating from Game Mode.

    Steam Deck tip: After updating to a new release, run Set up in Desktop Mode (without the Decky plugin) before launching from Game Mode.

    System Requirements

    • OS Windows 10 / 11 (64-bit), or Linux / SteamOS with Proton
    • CPU 64-bit x86 CPU with SSE4.2 & POPCNT (FMA3 / Haswell+ or Piledriver+ recommended for the faster build)
    • GPU Vulkan 1.3 capable GPU with an up-to-date driver
    • Memory & Storage 16 GB RAM and ~30 GB free disk space
    • Game Files Your own decrypted dump of Fire Emblem: Fortune's Weave at update 131072
